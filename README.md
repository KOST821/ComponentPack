# Component Pack

Welcome to the **Component Pack**! This is a collection of ready-to-use, highly customizable component scripts and shaders to drop directly into your Godot 4 project.

## 🚀 Features at a Glance
- **Health, Combat & Projectiles:** Includes separated 2D and 3D modules for Health, HitBox/HurtBox, and Projectile Movement.
- **State Machines:** Provides both Classic (Node-Based) and User-Based (`RefCounted`) Finite State Machine setups.
- **Visual Effects & Animation:** Features screen shake, squash-and-stretch animations, one-time self-cleaning animations, a flip sprite tool, and multiple scene transition shaders (Fire, Laser, Radial Tech-Grid, Slice, and Wave).
- **Core Mechanics & Utilities:** Packs in a drop rate manager, gravity controller, input buffer, drag and drop system, interactive UI module, scene spawner, config save system, and a zero-code debug utility.

*You can check everything included in this pack [here](addons/ComponentPack/).*

---

## 📦 Installation

1. Download the latest ***release*** *(this ensures that the addon does not contain any work-in-progress files)*.
2. Copy the `addons/ComponentPack` folder into your Godot project's `addons/` directory (`res://addons/ComponentPack/`).
3. Open your project in Godot and navigate to **Project -> Project Settings -> Plugins**.
4. Enable **ComponentPack**.
5. Add any component directly from the **Create New Node** (`Ctrl + A`) dialog!
