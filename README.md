# Component Asset Pack

Welcome to the **Component Asset Pack**! This is a collection of ready-to-use, highly customizable component scripts and shaders to drop directly into your Godot 4 project.

## 🚀 Features at a Glance
- **Health & Combat:** Includes separated 2D and 3D modules for Health. It also contains 2D and 3D HitBox and HurtBox components.
- **State Machines:** Provides both Classic and User-Based Finite State Machine setups.
- **Visual Effects:** Features screen shake functionality and squash animations. It also includes a flip sprite tool and multiple scene transition shaders like Fire, Laser, Radial Tech-Grid, Slice, and Wave.
- **Core Mechanics:** Packs in a drop rate manager, a gravity controller, and an input buffer. It also provides a drag and drop system, an interactive UI module, and a scene spawner.  

## 📦 Installation
1. Download the latest release from the Releases tab.
2. Extract the ZIP file.
3. Drag the `ComponentAssetPack` folder into your Godot project's `res://` directory.
